# Cutline Studio

> **Ilha de edição profissional de vídeo, áudio e color grading direto no navegador. Processamento 100% local com WebGPU, WebCodecs e Web Audio API.**

**Cutline Studio** é uma estação completa de pós-produção web desenvolvida em React, TypeScript e WebGPU/WebCodecs, projetada para entrega rápida de vídeos, reels, podcasts e peças cinematográficas sem necessidade de instalação ou upload de arquivos para servidores externos.

---

## Recursos Principais

- **Processamento 100% Local (Client-Side):** Seus vídeos permanecem no seu dispositivo com privacidade total e renderização acelerada por hardware.
- **Timeline Multipista Profissional:** Faixas ilimitadas de vídeo, áudio, imagem, texto e gráficos com corte de precisão, ripple delete, snap magnético e keyframes.
- **Modo Demo Instantâneo:** Gerador procedural embutido que cria cenas animadas em WebM, trilha sonora WAV com batida rítmica e títulos editáveis em 1 clique para testar todo o estúdio imediatamente.
- **Color Grading Cinematográfico:** Perfis prontos de cinema (*Kodak 2383*, *Teal & Amber*, *Noir 16mm*, *Golden Hour*, *Doc Limpo*), além de rodas de cor, curvas RGB, HSL e suporte a LUTs 3D (`.cube`).
- **Suíte Completa de Áudio & Decupagem:** Equalizador, compressor, redução de ruído em 3 estágios, detecção de batidas e corte automático de silêncios por dB com visualização de waveform.
- **Exportação Avançada:** MP4 (H.264/H.265), WebM (VP8/VP9/AV1), ProRes, sequências de imagem e áudio dedicado (WAV, MP3, AAC, FLAC, OGG).

## Desenvolvimento Local

```bash
# Instalar dependências (Node.js 20+ e pnpm)
pnpm install

# Iniciar ambiente de desenvolvimento
pnpm dev

# Build de produção
pnpm build
```
